# noctalia-plugins

Plugins for the [Noctalia](https://github.com/noctalia-dev) shell.

| Plugin | What it does |
| --- | --- |
| [octobar](octobar) | GitHub pull requests, reviews, comments and mentions in the bar, with notifications and tracked branches. |

```sh
noctalia msg plugins source add sn4pe git https://github.com/Sn4pe/noctalia-plugins
```
